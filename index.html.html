    How to Play

    Cross a dangerous candy world by drawing your own platforms. Reach the glowing exit door before the timer runs out.

    Controls

    A / ←
    Move left
    D / →
    Move right
    Space
    Jump (hold it down and you still jump only once)
    Mouse drag
    Hold the left button and drag to draw. Release to turn the line into a solid platform
    Esc
    Pause or resume

    The drawing mechanic

    • Drawn lines are solid on top. Land on them, walk up sloped lines, and use them as bridges over gaps.
    • Longer lines cost more ink. The ink meter drains as you drag and the line stops when the bottle is empty.
    • Undo Last Drawing and Clear All Drawings give the ink back.
    • Collect ink bottles to refill 120 ink.
    • Turn on Pixel View to see the Bresenham pixels that rasterise each stroke.

    Health, enemies and the goal

    • You start with 3 hearts. Purple jelly blobs, violet spikes, the spinning candy arm and falling into a gap each cost one heart.
    • Jump on a jelly blob from above to squash it for bonus points.
    • Coins give 10 points and stars give 50.
    • Reach the exit door to clear the level. Spare time and hearts add bonus points, and your score carries into the next level.
    • There are 5 levels. Each one has a longer map, wider gaps and more hazards than the last.
    • You lose if your hearts reach zero or the timer ends.

    Draw to Survive

    Project type: Computer Graphics

    Technology: HTML5, CSS3, JavaScript and the Canvas API. One self-contained file with no libraries and no external assets.

    Algorithms implemented from scratch

    DDA line drawingBresenham line drawingTranslationRotationScalingComposite transformationsCohen–Sutherland clippingFlood FillBoundary FillSegment collision detection

    Where each idea appears in the game

    • Bresenham: every drawn stroke is rasterised into integer pixels (see Pixel View).
    • Translation: player and enemy movement, camera scrolling.
    • Rotation: the spinning candy arm uses a rotation matrix, and so does its collision test.
    • Scaling: pulsing and flipping coins and stars.
    • Collision detection: point-on-segment tests for sloped platforms, box tests for enemies, spikes, coins and the exit.
    • DDA, composite transforms, clipping and fills: interactive demos in the Computer Graphics Lab.
